Important notes

This app is a helper only. It does not replace official charts, a marine compass, VHF radio, GPS plotter, navigation training, or local boating rules.

This version intentionally removes the phone compass sensor because phone compass readings can be unreliable near metal, speakers, magnets, engines, wiring, or some phone cases.

GPS permission

GPS usually requires Location permission and may require the app to be opened from an HTTPS page. If GPS is denied, check Chrome Location permission and reload the app.
